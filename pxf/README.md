# Effect Lab

공개판은 Dusk 평가기, 공개판 설정 정의, 공개판 생성기, 독립 14종 템플릿 렌더러로 구성됩니다.

- `dusk_engine.mjs`: 29종 노드 연결 평가·필터·합성.
- `generators.mjs`: 공개판 도형·리본·곡선·광선·파티클·번개.
- `node_contract.mjs`: 공개판에서 직접 정의한 UI 필드·초깃값·검증 범위.
- `legacy_engine.mjs`: Dusk 시작 템플릿의 기존 렌더러.
- `engine.mjs`, `pxf_schema.mjs`: 데이터 검증, 가져오기와 PNG/Godot 내보내기.
- `app.mjs`, `index.html`: 작품 목록·편집·AI 요청 화면.

원본 사이트의 렌더러와 카탈로그를 다운로드할 필요가 없습니다. 29종 노드 이름이 같더라도 기본값과 세부 표현은 다릅니다. 원본에 맞춘 private/native 렌더러와 시각적으로 동일하다는 의미는 아닙니다. 엄격한 호환이 필요한 데이터는 가져온 뒤 프레임을 확인하세요.

저장 JSON의 `renderer`는 `dusk-public@1`입니다. 파일을 가져와서 열기만 하는 것으로 기존 파일을 덮어쓰지는 않습니다. 사용자 작품은 해당 사용자의 권리와 이용 조건을 따릅니다.
