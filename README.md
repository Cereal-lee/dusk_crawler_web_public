# Dusk Crawler Workshop — Public Edition

픽셀 이펙트, 로컬 BGM, 이미지, 아이템, SD 캐릭터를 만드는 개발용 웹 공방입니다.
이 저장소는 개인 작업실에서 필요한 코드만 선별한 **별도의 공개판**입니다. 개인 저장소의 Git 기록, 운영 계정, 작품 라이브러리, API 키는 포함하지 않습니다.

## 시작하기

Node.js 22.13 이상이 필요합니다. 다른 사람의 컴퓨터에서도 설치 후 실행할 수 있습니다.

```sh
npm ci
npm test
npm run dev
```

`http://127.0.0.1:4173/`을 여세요. PXF 편집·재생·저장·내보내기는 API 키 없이 사용할 수 있습니다. 로컬 저장 파일은 `.local/`에 생성됩니다.

AI 생성은 선택 기능입니다. `.env.example`을 `.env.local`로 복사하고 자신의 `OPENAI_API_KEY`를 로컬 파일에 설정하세요. 키를 Git에 커밋하지 마세요. OpenAI API 이용 요금은 실행자의 계정에 청구되며, ChatGPT 구독과 별도입니다. 모델 접근 권한에 따라 선택 가능한 모델이 달라집니다. UI에 표시되는 가격은 코드에 기록된 참고 단가이므로 실제 이용 시 공식 가격표도 확인하세요.

## 다섯 가지 공방

| 경로 | 기능 | 실행 방식 |
|---|---|---|
| `/pxf/` | 노드 편집, 키프레임, PNG 시트, JSON, Godot SpriteFrames | 브라우저 Dusk 엔진 / 선택적 OpenAI 수정 |
| `/bgm/` | 프롬프트·레퍼런스 음원으로 음악 생성, 재생, 제목 관리 | 사용자 PC의 ComfyUI와 로컬 브리지 |
| `/image/` | 이미지 생성과 보관 | OpenAI API |
| `/item/` | 아이템 아이콘, 투명 배경 처리와 내보내기 | OpenAI API + 브라우저 처리 |
| `/sd/` | SD 캐릭터·동작 시트 생성과 편집 | OpenAI API + 브라우저 처리 |

12개의 Dusk 시작 템플릿을 포함합니다. 원본 SUILE 카탈로그 165개와 개인·게임 작품은 포함하지 않습니다.

## 이미지·아이템 제작 기록

내 작품 상세에서 원래 요청, 실제 생성 프롬프트, 처리 단계, 출력 크기와 Blender 스크립트를 확인하고 내려받을 수 있습니다. **제작 기록 가져오기**로 `dusk.artwork@1` JSON 묶음을 불러오면 원본 PNG와 완성 PNG를 현재 계정에 저장합니다. 가져오기는 AI를 호출하지 않으며, 같은 묶음을 다시 가져와도 중복 생성하거나 기존 작품을 덮어쓰지 않습니다.

묶음은 `format`, UUID `id`, `config`(종류 `image` 또는 `item`·프롬프트), PNG 데이터 URL `originalPng`·`processedPng`, `provenance`(프롬프트·처리 단계·출력 크기·스크립트)를 담습니다. 구체적인 형식은 `shared/art_import.mjs`와 `tests/art.test.mjs`를 참고하세요. 스크립트는 표시·다운로드만 하며 웹에서 실행하지 않습니다. 개인·게임 작품 묶음은 이 저장소에 포함하지 않습니다.

## 공개판 렌더러

고급 노드 29종을 지원하며 저장 시 `dusk-public@1`을 사용합니다. 기존 `pxf@1`, `dusk-native@1` 그래프의 기본값·선택 옵션·허용 범위와 픽셀 중심 샘플링, 입자 시드·생성 시점, 곡선 두께를 호환하도록 수정했습니다. 원본 실행 코드를 로딩하지 않고 Dusk 구현으로 처리합니다. 기존 `dusk-legacy@1` 시작 템플릿도 유지합니다.

2026-11-09 회귀 검증에서 운영 계정의 저장 작품 156개, 별도 로컬 JSON 143개 및 시작 템플릿 12개의 모든 프레임이 변경 전 Dusk native 엔진과 RGBA 단위로 일치했습니다. 원본 카탈로그 165개도 로컬에서 가져오기·전체 프레임 렌더링을 확인했습니다. 이 검사에 사용한 개인 작품·원본 카탈로그는 공개 저장소에 포함하지 않습니다. 원본 SUILE 엔진과 모든 입력에서 픽셀 일치를 주장하는 검사는 아닙니다.

58개 자체 합성 그래프의 고정 해시 회귀 테스트를 포함합니다. 29종 노드와 여러 도형·입자 형태, 방향, 시드, 이전 프레임 참조를 검사하여 기본값이나 렌더링 변경으로 기존 표현이 달라지는 것을 방지합니다.

## 서버 실행과 배포

`npm run dev`는 **127.0.0.1 전용 개발 서버**이며 하나의 로컬 계정을 사용합니다. 공용 네트워크로 노출하지 마세요.
`npm run build`는 `dist/server/index.js`에 Worker 모듈을 만듭니다. 운영 배포는 다음 구성을 별도로 준비해야 합니다.

- 인증된 프록시가 `oai-authenticated-user-id` 헤더를 검증·설정하는 환경. 클라이언트가 임의로 보낸 헤더를 신뢰하지 마세요.
- `DB` D1 데이터베이스와 `BUCKET` R2 버킷, `drizzle/`의 순차 마이그레이션.
- 서버 환경변수 `OPENAI_API_KEY`, 선택적 `OPENAI_MODEL`.
- Sites를 이용한다면 자신의 프로젝트에서 발급받은 `.openai/hosting.json`. 이 디렉터리는 Git에서 제외됩니다.

기존 운영 사이트의 식별자·DB·버킷·주소를 이 저장소에서 사용하지 않습니다. 이 저장소를 수정하거나 실행해도 기존 운영 공방에 배포되지 않습니다.
