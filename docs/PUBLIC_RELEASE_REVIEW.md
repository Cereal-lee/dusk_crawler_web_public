## 독립 구현의 범위

이전 작업에서 원본을 열람했으므로, 원본에 노출되지 않은 별도 인력이 수행한 clean-room 절차라고 주장하지 않습니다. 공개판은 원본 실행 코드를 로딩하거나 복사하여 제공하지 않으며, 현재 검증 기준은 변경 전 Dusk native 엔진의 저장 작품 출력입니다. 픽셀 중심 포함 판정, 3차 베지어 곡선, 결정적 입자 궤적, 필터 등 일반 알고리즘을 사용하며 원본 실행 코드를 공개판에 복사하지 않습니다.

공개판 API에 남은 노드/필드 식별자는 기존 작업 데이터와 소통하기 위한 기능적 이름입니다. 원본 설명문과 메타데이터 파일은 재배포하지 않습니다. 누락된 JSON 값의 의미를 유지하기 위한 기능적 기본값, 열거형 토큰, 숫자 범위는 공개판 정의에 반영합니다. UI 이벤트 처리, 가져오기 검증, 서버 저장, AI 요청 연결은 Dusk 개발 소스입니다. 원본 UI의 배치·문구·시각적 표현 재현을 제거하기 위해 공개판의 PXF 문서와 스타일은 새로 작성했습니다.

## 라이선스 범위

루트 MIT는 이 저장소에서 제공하는 Dusk 코드·문서에 적용합니다. Tomato Studio 자료의 원 저작권 및 MIT 고지는 `third-party-tomato-license.txt`에 보존합니다. 사용자가 입력한 데이터, 외부 서비스, 다운로드한 모델과 생성 결과까지 MIT로 재라이선스하지 않습니다. Pixel Composer의 MIT를 SUILE의 라이선스로 취급하지 않습니다.

이 문서는 소스 구성 및 출처 검토 기록이며 법률 의견서나 제3자 권리 부존재 보증이 아닙니다. 공개 이후 추가하는 코드·자료도 출처와 허락을 확인해야 합니다.

## 공개 경계 검사

`scripts/audit_public.mjs`는 추적 파일 목록 또는 Git 초기화 전 소스 목록을 검사합니다. 금지 경로, 운영 식별자, 대표적인 자격 증명 패턴, 배포 자산에 원본 엔진이 포함되는지를 검사하며 비밀 값은 출력하지 않습니다. 패턴 검사로 모든 종류의 비밀을 증명할 수는 없으므로, 최초 스냅샷의 파일 목록도 별도로 검토했습니다. 최초 공개 이력에 이전 원본 자료가 포함되지 않았음을 Git 루트 커밋으로 확인합니다.
