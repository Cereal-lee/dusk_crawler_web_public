# 걷기 색 구조 차트 — 직접 수정하는 법

여기 있는 차트는 전부 **평범한 PNG**다. 그림판·포토샵 등으로 수정하거나 새로 그려서
같은 이름으로 저장하면 끝 — 앱은 이 파일을 그대로 레퍼런스로 붙이므로 빌드·재시작 불필요
(스튜디오에서는 `public/sprite-guides/` 의 같은 이름 파일이 실제 사용본).

| 파일 | 비율 | 상태 |
|---|---|---|
| walk-structure-original.png | 팀장 원본 (2.5등신, 8포즈 스트립) | 기준 — 수정하지 말 것 |
| walk-cycle-color-grid.png | 2.5등신 4x2 격자 | 원본에서 자동 조립 |
| walk-cycle-color-grid-mini.png | 2등신 (머리:몸 1:1) | 다리 부호 8/8 검증 |
| walk-cycle-color-grid-4h.png | 4등신 | corr -0.90, 다리 8/8 |
| walk-cycle-color-grid-6h.png | 6등신 | corr -0.73, 다리 8/8 |

## 지켜야 할 규약 (이걸 어기면 생성이 그대로 따라 틀어진다)

1. **빨강 = 바깥쪽(화면에서 가까운) 팔과 다리, 파랑 = 안쪽 팔과 다리.** 머리·몸통은 회색.
2. **4x2 격자, 흰 배경**, 셀 사이 여백은 비워 둔다 (선 긋지 말 것).
3. 포즈 순서: 접지 → 리코일(최저) → 교차 → 하이포인트(최고) → 반대발 반복.
   **셀8은 셀1과 같은 중복 접지** — 재생 시트에서는 자동 제외된다(keep:7).
4. 발 굴림: 뒤꿈치 착지(발끝 들림) → 평발 → 발끝 밀기. 몸 높이는 리코일에서 낮고
   하이포인트에서 높게 — 이 오르내림도 생성에 그대로 복사된다.
5. 팔 스윙은 과장해서 크게 그릴수록 좋다 — 생성 과정에서 진폭이 감쇠된다(실측).

## 수정 후 검증 (필수)

```
node standalone/check-color-chart.mjs guides/walk-cycle-color-grid-4h.png --heads 4 --ref guides/walk-cycle-color-grid.png
```

- `--ref`: **4x2 격자 차트만** 기준이 될 수 있다 (검사 스크립트가 ref 도 4x2 로 읽는다).
  `walk-structure-original.png` 은 8포즈 스트립(2048x256)이라 ref 로 넣으면 기준 측정이
  틀어져 항상 5/8 로 오판된다 — 팀장 원본과 대조하려면 격자 재조립본(walk-cycle-color-grid.png)을 쓸 것.
- `--heads`: 2 | 2.5 | 4 | 6 (등신에 따라 팔·다리 측정 위치가 다름)
- **다리 부호 일치 8/8 + corr 음수**면 합격. 2등신은 팔 수치가 노이즈이므로 다리와 육안으로.
- 이미지 모델로 차트를 다시 뽑는 경우: 미러 행(5~8셀)에서 팔 색이 뒤집히는 사고가 흔하다
  (실측: 8장 중 1장만 통과한 적 있음). 반드시 여러 장 뽑아 검사로 골라라.
